Automation Portfolio

1. Automated Coordination Tracker (Power Query + Power Automate)
Executive Summary

Context: Asia Pacific Recruitment Operations
Role: Recruitment Operations / Talent Analytics
Tools Used: Power Query, Advanced Excel, Power Automate
Impact: Reduced manual coordination tracking effort by ~6–7 hours/week and improved real-time visibility of interview coordination status.

Business Problem Statement
  • Interview coordination was tracked manually across multiple Excel sheets.
  • Data was inconsistent due to frequent manual updates and version issues.
  • Multiple stakeholders relied on different tracker versions.
  • No real-time visibility of interview scheduling status.
  • High manual effort required for updating and validating coordination data.
Solution Architecture
  • Consolidated all coordination inputs into a single structured dataset.
  • Built Power Query logic to clean, standardize, and merge multiple trackers.
  • Created refreshable model for real-time updates.
  • Automated data transformation to ensure consistent interview tracking status.

Flow: Data Sources → Power Query Cleaning → Data Merge → Status Logic → Unified Coordination Tracker → Refresh Output

Measurable Impact
  • Reduced manual tracking effort by ~6–7 hours/week.
  • Eliminated dependency on multiple Excel trackers.
  • Improved accuracy and consistency of coordination data.
  • Enabled real-time visibility for stakeholders.
  • Reduced human error from manual updates.
2. Automated Onboarding Tracker (Power Query & Excel)
Executive Summary

Context: Asia Pacific recruitment operations
Role: Recruitment Operations
Tools Used: Power Query, Advanced Excel, Data Modeling
Impact: Reduced manual tracking effort by 10 hours/week, improved onboarding visibility across 13 APAC countries

Business Problem Statement
  • Onboarding status was tracked manually across multiple Excel files.
  • Inconsistent tracker updates.
  • Manual consolidation required frequent copy-pasting.
  • Leadership lacked real-time onboarding visibility.
  • Error rate due to duplicate entries and mismatched data.
  • High time consumption.
Solution Architecture

Data Sources

  • Offer release tracker (Pulled via ATS - Avature)
  • Candidate onboarding sheet stored in XLS

Power Query Logic Applied

  • Cleaned inconsistent headers.
  • Created calculated columns.
  • Built conditional logic for onboarding status.
  • Created refreshable Power Query with one-click update.

Flow: Data Sources → Power Query Cleaning → Data Merge → Status Logic → Output

Measurable Impact
  • Reduced manual consolidation time from 10 hours/week.
  • Enabled visibility across 13 APAC countries.
  • Clear view of Offer vs Joined candidates.
  • Improved tracking efficiency.
  • Reduced duplicate record errors by 100%.
3. Automated Interview Scheduling Emails (Power Automate)
Executive Summary

Context: APAC Recruitment Coordination Process
Role: Recruitment Operations
Tools Used: Power Automate, Outlook, Excel
Impact: Reduced manual interview scheduling email effort by ~4–5 hours/week

Business Problem Statement
  • Interview scheduling emails were sent manually for every request.
  • High repetitive effort for formatting and sending emails.
  • Risk of delays in coordination communication.
  • No standardized email structure across recruiters.
  • Dependency on manual intervention for every scheduling update.
Solution Architecture
  • Extracted interview details from structured Excel tracker.
  • Built Power Automate cloud flow for email generation.
  • Designed dynamic email templates.
  • Integrated Outlook for automated distribution.

Flow: Interview Data → Power Automate Trigger → Dynamic Email Body → Outlook Distribution

Measurable Impact
  • Reduced manual email effort by ~4–5 hours/week.
  • Standardized interview communication format.
  • Faster turnaround time for scheduling emails.
  • Reduced dependency on manual coordination steps.
4. LIA (TA Partner Chatbot) (Microsoft Teams – Microsoft 365)
Executive Summary

Context: Talent Acquisition Operations Support
Role: Recruitment Operations / TA Enablement
Tools Used: Microsoft 365, Teams, Chatbot (Copilot/Power Virtual Agent)
Impact: Reduced repetitive TA queries and improved self-service resolution

Business Problem Statement
  • TA partners frequently raised repetitive queries.
  • HR Ops team spent significant time answering same questions.
  • No centralized self-service system.
  • Delayed responses impacted efficiency.
  • Lack of scalable FAQ support system.
Solution Architecture
  • Built chatbot using Microsoft 365 and deployed in Teams.
  • Configured predefined responses for TA queries.
  • Integrated structured knowledge base.
  • Enabled instant response system.

Flow: User Query → Chatbot Engine → Knowledge Base → Instant Response

Measurable Impact
  • Reduced repetitive TA queries by ~60%.
  • Improved response time from hours → instant.
  • Reduced dependency on HR Ops team.
  • Improved TA partner experience.
